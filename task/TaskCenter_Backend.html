🆕 「每日任务统计」：呈现任务完成后的成效，按 每日 统计（时区 UTC+8 · 结算 23:59:59）。
  • 报表范围：仅统计任务时间设定为「每日」的任务；其他任务时间（每周／永久／限时／周限时）不纳入本报表。
  • 完成人数＝当日完成此任务的去重人数，点击数字可查看完成用户清单。
  • 栏位依「任务 → 完成情况 → 奖励 → 完成任务期间 → 完成后」分组；除任务目标值外，数值皆为当日完成此任务全部用户的总计。
  • 任务完成值 / 有效投注 / 充值金额：统计口径为该用户「当日任务开始 → 任务完成当下」期间的累计（与任务时间同一区间，非完成后数据）。
  • 任务完成后第一笔充值：任务完成后才起算，至当日任务时间结束为止（用户完成任务后的第一笔充值金额）。
  • 奖励金额：仅计入已实际发放的部分（发放状态＝自动发放 或 已领取），不含待领取 / 待审核 / 未通过 / 已过期。
  • 组任务：依各「子任务」分别记录（任务id 显示为母ID-序号，如 1030-1），每个子任务完成记一笔；设了 2 个条件（AND）的，2 个都达标才算完成。
  • 组任务的「额外奖励」：每一档单独一行（任务id 为母ID，名称标示「任意完成 n 个」）；完成人数＝当日达成该档的去重人数，奖励金额＝该档已发放的奖励总计。
