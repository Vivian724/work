2.3

后台 · 任务内容（任务组）

一个任务组＝多个子任务，完成一个领一个；完成到指定数量，再送额外奖励。

子任务

  • 数量：预设 2 个，最少 1 个，最多 10 个。
  • 内容：每个子任务一个名称＋一个条件＋一份奖励＋一个跳转；条件、奖励、跳转规则同 2.2。
  • 子任务名称 *：子任务卡片里的「名称」，规则同「任务名称」（必填、国际化）；前台子任务行显示这个名称。任务组名称＝上方「任务名称」。
  • ID：母ID-序号，显示在每个子任务标题旁。新增任务时删除会重排；编辑时序号不变，删掉的号码不再用，新加的接最大号。
  • 任务时间：整组共用，在 2.6 设定。

额外奖励

  • 写法：「任意完成 n 个」＋奖励。不限哪几个、不分先后。
  • 档数：必填，最少 1 档，最多 3 档，且不超过子任务数；每档 n 不重复。
  • 发放：每档发 1 次，不受名额限制。
  • 计算：完成数按当期算，跟着任务时间重置。

例子左侧画面带入的就是这个例子

子任务：① 充值 ₱100 → 积分 100　② 投注 ₱1,000 → 积分 150　③ 投注 ₱200 → 积分 200
额外奖励：完成 1 个 → 积分 50　2 个 → 彩金 100　3 个 → 积分 500

会员做了完成数拿到
② 投注 ₱1,0001 / 3积分 150 ＋ 积分 50
① 充值 ₱1002 / 3积分 100 ＋ 彩金 100
③ 投注 ₱2003 / 3积分 200 ＋ 积分 500

补充

  • 子任务删到比某档 n 还少：该档 n 清空，由运营重选或删除。
2.4

后台 · 名额上限

名额上限＝一项奖励最多发给几个人，先到先得。在「任务内容」区最下方设定。

规则

  • 怎么填：正整数；留空或 0＝不限。任务时间选「永久」时反灰，显示「不限」。
  • 基础任务：这个任务的奖励最多发给 N 人。
  • 任务组：每个子任务各自计算，共用同一个上限数字。
    例：填 1000 → 子任务1 最多 1000 人、子任务2 最多 1000 人……互不影响。额外奖励不受名额限制。
  • 怎么算人数：奖励发出就算 1 人；同一人一期只算一次，之后没领、超过领取时限也照算。每一期重新计算。
  • 满了：之后完成的人不发奖励，后台记录「名额已满」，前台按钮「额满」（3.5）。

补充

  • 人工审核：以「审核通过」那一刻算。
  • 奖励找回补领：当期已算过，补领不再算。
  • 当期改小名额：已发的不收回；已发人数 ≥ 新上限即额满。
2.5

后台 · 参与对象

决定谁能参加，前台照配置展示：VIP、标签不符合＝看不到；参与要求没达成＝看得到，按钮照 v1.1 第二层（去认证／去充值／去投注）；名额满＝「额满」。

规则

  • VIP 等级：多选 VIP0～VIP4；都不勾＝不限。
  • 用户标签：多选，分一级、二级标签；都不勾＝不限。勾多个＝全部都要有（AND）。例：勾 TH、ML，会员要同时有 TH 和 ML 才能参加。
  • VIP 与标签：要同时符合（VIP 在勾选范围内，且标签全部都有）。
  • 任务参与要求：选填，勾了才生效：完成KYC／完成KYC部分认证、累计充值区间、累计有效投注区间。累计的算法照既有。
  • 充值及有效投注资格（新增）：两个区间都勾时，选一个：「符合任一条件」＝充值、投注其中一个在区间内就行；「完全符合」＝两个都要在区间内。预选完全符合。

补充

  • 区间没勾：最低、最高反灰。
  • 最低留空＝从 0 起算；最高留空＝不设上限。
  • 最高比最低小：最高清空重填。
2.6

后台 · 时间与发放

设定任务什么时候有效、怎么审核、奖励怎么发。

规则

  • 任务时间 *：永久／每日／每周／限时（起讫日期时间）／周限时（星期几 至 星期几）。周期照既有。
  • 条件搭配：条件不支持的任务时间反灰（下表）；任务组取所有子任务都支持的时间。
  • 审核方式 *：自动审核／人工审核；人工以「审核通过」为完成。
  • 奖励发放方式 *：自动发放／用户手动领取；子任务、额外奖励照同一设定。
  • 奖励领取时限：只在「用户手动领取」＋每日／限时出现，单位天；对应奖励找回（3.8），额外奖励不适用。
  • 排序：任务组和基础任务一起排，数字越小越前面（照既有）。
条件永久每日每周限时周限时
信息完善、一次性标记（2025新版访问、体验平台PWA、关注Facebook）✓————
资金（充值、投注、Maya／Glife 充提）—✓✓✓✓
品牌活动（圣诞倒计时、Brand Daily Passcode）———✓—

补充

  • 限时：结束早于开始不能选；开始改到结束之后，结束清空。
  • 已选的任务时间变成不能用：自动改成第一个可选的。
  • 任务组：子任务下拉里，跟其他子任务没有共同任务时间的条件反灰（例：已有「投注」，不能选「关注Facebook」）；新加的子任务自动带可以放一起的条件。
  • 适用端口、是否显示任务简介、任务简介、任务状态：照既有；任务简介在前台的显示见 3.10。
2.7

后台 · 任务设置列表

位置：运营后台 › 任务中心管理 › 任务设置。列表一行一个任务。

规则

  • 任务ID：基础任务一个 ID；任务组显示母 ID，下方列出子任务 ID「母ID-序号」，例：1030-1。
  • 任务类别：基础任务／任务组。
  • 任务条件、任务奖励：条件显示「大类」＋下一行「条件 目标值」；任务组每个子任务一行，奖励栏最后一行列额外奖励。券类显示券名。
  • 适用等级/层级：显示勾选的 VIP＋标签；VIP 全选或都没勾显示「全部VIP」，标签没勾显示「不限标签」。
  • 任务参与要求：列出勾选的要求；两个区间都勾时，加显示「完全符合／符合任一」；没勾＝「不限」。
  • 名额：基础任务「已发送 / 上限」，满了加红字「已满」；任务组「每项上限 N」；没设或永久＝「不限」。
  • 任务时间：限时显示起讫时间；周限时显示「星期一 至 星期五」这类区间。

补充

  • 分页：任务设置、任务完成记录、任务报表统计有调整（画面标橘色「有调整」）；资料审核、黑名单设置不变。
  • 任务名称（＋国际化）、适用端口、审核方式、排序、任务状态、操作：照既有。
2.8

后台 · 任务完成记录

一行＝一位会员的一笔奖励。

规则

  • 子任务：ID＝子任务 ID（1030-1）；名称「任务组名称 · 子任务名称」＋「子任务」标签。
  • 额外奖励：ID＝母 ID（1030）；名称「任务组名称 · 额外奖励 · 任意完成 n 个」＋「额外奖励」标签。
  • 券类奖励：奖励类型下方显示券名，奖励值显示张数。
  • 名额已满：完成时名额已满、不发奖励；状态红字，奖励值「—」。发放状态筛选多这个选项。
  • 搜索任务ID：母 ID（1030）＝整组（子任务＋额外奖励）；子任务 ID（1030-2）＝只列该子任务；比对要完全相同（搜 103 不会出现 1030）。

补充

  • 其他状态照既有：待审核、待领取、自动发放、已领取、审核未通过。没有「已过期」状态。
2.9

后台 · 任务报表统计

按任务汇总所选时间区间（UTC+8）的完成次数和发放量。

规则

  • 券类栏位：累计发放免费旋转、免费投注、优惠券、golden draw券，单位张；没有就显示「—」。
  • 任务组：一行汇总＋下方明细，明细一律展开显示，不做收合。
    • 汇总行：ID＝母 ID（1030）；完成次数＝子任务相加；发放＝子任务＋额外奖励。
    • 子任务行：ID＝子任务 ID（1030-1），名称＝子任务名称。
    • 额外奖励行：每档一行，ID＝母 ID（同 2.8），名称「额外奖励 · 任意完成 n 个」；完成次数＝达成该档的人次，不算进汇总。
  • 累计完成次数：按完成时间计，含名额已满没发到的；人工审核以通过才算。
  • 累计发放：会员实际领到的（自动发放＋已领取＋找回补领），按领取时间计（自动发放＝完成时间）；待领取、待审核、审核未通过、名额已满不算。
  • 小计／总计：小计＝本页，总计＝全部查询结果；都只加基础任务行＋任务组汇总行，明细不重复加。

补充

  • 搜索：币别、时间区间、任务名关键字照既有；任务组用任务组名称比对，搜到整组列出。
  • 任务ID 搜索（新增）：同完成记录（2.8）。母 ID（1030）＝汇总行＋全部明细；子任务 ID（1030-2）＝只列该子任务一行，小计、总计就是这一行。
  • 分页：按任务算，任务组整组算 1 笔，明细不拆到下一页。
  • 导出：内容同画面，含任务组明细行。

前台 · 任务列表页签

页签按后台「任务时间」分类。

页签显示下方红字
全部(n)看得到的全部任务不显示
基础任务永久*任务完成后不会重置

规则

  • 页签分类：只看任务时间，不看任务类别。例：永久的任务组在「基础任务」页签。
  • 红点：该页签所有可领取的数量，基础任务、子任务、额外奖励都要算（每个「领取」按钮、每个可领宝箱各算 1）；黑名单、未登录不显示；领取后立即减少。
  • 卡片顺序：由后端排好，前台照着显示：
    • 后台排序越小越前面，任务组卡和基础任务卡一起排（2.6）。
    • 已完成、额满的排到最下方。任务组要子任务、宝箱全部完成或额满才算（因子任务额满而达不到的宝箱，当作完成）。
    • 刚领取完不重排（不重打 API），卡片留在原位；下次进页面才到最下方。
  • 已完成、额满：任务时间结束前仍留在列表上，倒数照常显示；任务组整组做完也一样。

前台 · 基础任务卡

左边任务资讯，右边倒数和一个按钮。

规则

  • 标题：一行，超出以「…」截断。
  • 进度：资金类＝进度条＋「₱已达成 / ₱目标」；其他条件＝「进度 0 / 1」。
  • 奖励标签：图示＋内容：彩金、积分显示数值；免费旋转、免费投注、优惠券显示券名；golden draw券显示「×张数」。
  • 已发送人数：「已发送 x / y 人」，有设名额才显示，满了变红字；永久任务不显示。
  • 倒数：按钮上方红字，例「⏱ 6d 13:05:11」；永久任务不显示。
  • 按钮：照既有逻辑；名额满显示「额满」（3.5）。
  • 任务简介：标题后面的 ⓘ，照既有（3.10）。

前台 · 任务组卡

一张卡＝一个任务组：上方标题、进度、额外奖励，下方子任务。

规则

  • 角标、倒数：左上「任务组」，右上倒数（永久不显示）。
  • 任务简介：ⓘ 放在任务组标题后面，子任务没有，照既有（3.10）。
  • 进度：「已完成子任务数 / 子任务总数」，达成就算（含还没领的）；人工审核的任务，审核通过才算。
  • 子任务行：标题＝后台配置的子任务名称（2.3），一行超出以「…」截断；其余同基础任务卡，每行一个按钮。
  • 收合：预设显示前 2 个，「查看全部（n） ⌄」展开、「收起 ⌃」收回；子任务 ≤ 2 个不显示。
  • 子任务顺序：领取 → 进行中（含处理中、未通过）→ 已完成／额满；同顺位照后台顺序。领取后下次进页面才重排。

补充

  • 游戏分类页的「Task」区块不显示任务组（任务组不适用「游戏页展示」，2.1）。
3.4

前台 · 额外奖励

任务组卡上方的浅黄区块，一档一个宝箱，最多 3 个。

宝箱样子点了
未达成灰色宝箱不能点
可领取亮色＋橘框，上下跳动领取 → 成功弹窗（3.6）→ 打勾
已领取绿色打勾不能点

规则

  • 宝箱下方：「n 个」＋奖励内容；宝箱之间的进度条走到目前完成数。
  • 发放方式：自动发放＝达成直接打勾；用户手动领取＝宝箱跳动，点了才领。
  • 限制：不受名额限制；不进奖励找回，要在本期结束前领。
  • 黑名单、未登录：宝箱全部灰色、不可点。
3.5

前台 · 按钮与额满

按钮的显示判断、点击行为、引导跳转全部照既有《任务按钮显示规则 v1.1》，没有变更。只多一个「额满」。

额满

  • 何时显示：奖励名额已满，且这位会员本期还没拿到这项奖励；已拿到的照既有逻辑。
  • 优先顺序：额满只取代「还没完成」时的按钮；处理中、未通过照 v1.1 显示。人工审核通过时名额已满 → 改显示额满。
  • 样式：不可点；淡灰玫瑰底、白字（日间 #e2b4b4、夜间 #8a6464）。
  • 同时：「已发送 x / y 人」变红字。
  • 适用：基础任务、子任务；新的一期名额重算后恢复。

补充

  • 「领取任务」「已过期」：v1.1 里有，但目前没有这两个状态，前台不会出现，不用做。
  • 审核未通过：显示「未通过」（照 v1.1）。

3.8

前台 · 奖励找回

任务重置或结束后，还在「奖励领取时限」内没领的奖励，在这一页补领。

规则

  • 入口：任务列表标题下方「奖励找回 ›」，红色数字＝可找回笔数。
  • 清单：一行一笔：任务名称、奖励、剩余可领时间。只有基础任务、子任务（名称「任务组名称 · 子任务名称」），没有额外奖励。
  • 底部：不显示合计（奖励类型可能混合），只放「一键领取」。
  • 一键领取：全部领取 → 弹窗：通用奖励图示＋「奖励领取成功」，不列奖励内容。之后清单清空、入口数字隐藏。
  • 没有可找回：显示「暂无可找回的奖励」，按钮反灰。

补充

  • 补领不占名额（2.4）；黑名单按钮反灰；未登录不显示入口。
3.9

前台 · 底部弹窗

会员完成任务时，底部跳出弹窗提醒。这是既有功能，只改两件事，其余照既有。

只改两件事① 图示、奖励依类型显示：原本只有积分、彩金有图示，免费投注显示「Free Bet」、借用积分图示；改为每种奖励用自己的图示。
② 停留 3 秒：原本手动领取不自动关、自动发放 5 秒；改为两种都 3 秒自动关。

规则

  • 文案：固定「奖励{a}，恭喜完成{b}任务！」。
    • {a}＝这笔奖励，写法同领取成功弹窗（3.6），例：₱50、+100、ON色碟、×1。
    • {b}＝任务名称；子任务、额外奖励一律用任务组名称。
  • 图示：放最左边，依这笔奖励的类型显示，同任务卡（3.2）的奖励图示。
任务按钮关闭
手动领取「领取」3 秒自动关；可点 × 或「领取」提前关
自动发放没有3 秒自动关；可点 × 提前关

照既有

  • 检查：登录进站约 2 秒后开始，每 10 秒检查一次新完成的任务；分页在背景时暂停。
  • 页面：任何页面都跳（含游戏页、活动页）；下载页、404、维护页、App 内嵌模式不跳。
  • 不跳：正在任务中心页面时（之后也不补跳）；账号任务功能被封锁（黑名单）。
  • 次数：同一任务只跳一次（任务组：每个子任务、每档额外奖励各一次）。记录存在浏览器，登出再登录会清掉，后端还回传就再跳。
  • 多笔：每 10 秒跳一个，不会同时跳出。
  • 点「领取」：直接跳转，不另跳确认弹窗；手机版到奖励中心（/reward-center），电脑版到任务中心（/user/task-center），弹窗关闭。
3.10

前台 · 任务简介

任务标题后面的 ⓘ，点了看任务简介。这是既有功能，本期不改。

规则（照既有）

  • 显示：后台「是否显示任务简介」选「是」才显示 ⓘ；选「否」不显示（2.6）。
  • 位置：基础任务在标题后面；任务组在任务组标题后面，子任务没有。
  • 弹窗：点 ⓘ 跳「任务介绍」弹窗，内容＝后台「任务简介」；点「确定」或 × 关闭。
