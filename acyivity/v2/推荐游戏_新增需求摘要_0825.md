# 预约活动 v2.1 —— 8/25 新增需求摘要

> 对应文件：`activity_v2_spec.html`（预约活动 v2.1 规格书）
> 本次新增功能：**推荐游戏**（后台设置）＋ **预约成功弹窗**（前台展示）

---

## 一、后台新增需求（步骤 4 — 活动条件）

### 新增字段：推荐游戏

| 项目 | 内容 |
|---|---|
| 位置 | 置于步骤 4「活动条件」页**最下方**，紧接在既有「适用游戏范围」栏位下方（两者一并置底；「适用游戏范围」本身不异动） |
| 必填 | 否 |
| 选择方式 | 与「适用游戏范围」相同（点击按钮开启游戏选择弹窗，依类别全选／单选、按钮显示已选数量），**惟弹窗内不含「体育」类别**（体育为投注类型而非单一游戏，无法产生对应游戏卡片，故排除） |
| 数量上限 | 最多 **4 款**；已选满 4 款时，其余游戏选项呈灰显 disabled 状态（无法点击勾选），鼠标悬停（hover）时显示提示「已达上限，请先取消勾选其他游戏」 |
| 与「适用游戏范围」关系 | 两者为**独立选择项**，互不影响，可分别勾选不同游戏，彼此无从属关系 |
| 用途 | 玩家预约成功时，于前台「预约成功」弹窗推荐显示 |
| 未选择时 | 弹窗不显示推荐游戏区块（呈现既有弹窗样式，与本次新增前完全一致） |
| 显示顺序说明 | 前台显示顺序依选择弹窗中的**固定列表顺序**（同「适用游戏范围」的类别／游戏排列方式），**非**依后台点选的先后顺序 |

## 二、前台新增需求（预约成功弹窗）

### 基本原则
「预约成功」弹窗本身为**既有样式**（标题／副标／CTA 按钮／右上角关闭「✕」皆不异动），本次**仅新增「为你推荐」游戏区块**，以及 CTA 按钮点击后新增的跳转逻辑。

### 触发规则
- 触发时机：玩家完成预约操作、系统判定**预约成功**的瞬间立即弹出
- 推荐游戏取值来自后台步骤 4「推荐游戏」设置，最多 4 款
- 后台未选择任何推荐游戏时：弹窗呈现既有样式，不显示「为你推荐」区块
- 每次预约成功皆弹出，不因玩家先前已关闭过而抑制

### 排版规则（推荐游戏数量 → 呈现方式）
卡片仅显示**游戏缩略图**（不附加游戏名称文字），固定采 2 栏排列：

| 推荐游戏数量 | 排版方式 | 说明 |
|---|---|---|
| 0 款 | 既有弹窗样式 | 不显示「为你推荐」标题与游戏卡片 |
| 1 款 | 单张居中 | 仅 1 张卡片，置于弹窗正中间 |
| 2 款 | 左右一排 | 2 张卡片同排左右并列 |
| 3 款 | 2＋1 三角形 | 第一排 2 张左右并列，第二排 1 张水平居中 |
| 4 款（上限） | 2×2 两排 | 每排 2 张，共两排 |

### 点击行为（完整穷举）

| 情境 | 操作 | 跳转结果 |
|---|---|---|
| 情境一：后台**未配置**推荐游戏（0 款） | 点击 CTA 按钮（既有按钮，文案不异动） | 跳转至**首页**（既有行为，不异动） |
| 情境二：后台**已配置**推荐游戏（1～4 款） | 点击任一推荐游戏卡片 | 关闭弹窗，跳转至**该卡片对应的游戏** |
| 情境二：后台**已配置**推荐游戏（1～4 款） | 点击 CTA 按钮 | 关闭弹窗，**随机**跳转至已配置的推荐游戏中的其中一款 |
| 不限情境 | 点击右上角关闭「✕」 | 关闭弹窗，停留在原页面（既有行为，不异动） |
