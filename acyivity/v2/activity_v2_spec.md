## 1. 需求目的

为提升已预约用户的活动参与度与奖励认领率，新增红点提醒与站内信提醒机制，让用户能即时得知「活动开启」与「奖励可领取」两种状态；同时开放后台设置「预约活动」是否显示于前台 Rewards → Promotion 列表，使预约活动比照既有活动模板呈现于该列表页。

**🆕 8/25 新增：** 新增「推荐游戏」设置与「预约成功」弹窗，让玩家预约成功后能立即被引导至指定游戏，提升导流效果。

## 3. 前台规格

### 3.1 红点提醒

适用范围：首页浮窗 / 活动卡片 / Rewards Promotion 列表

#### 两种红点情境（各自独立触发，呈现方式不同）

> 两情境触发条件互不影响，**可能同时成立**，显示逻辑已统一：情境一或情境二任一成立，所有位置（首页浮窗／卡片、底部导览／Banner／Expand）皆会显示提醒。

| 项目 | 情境一：活动开启提醒 | 情境二：奖励领取提醒 |
|---|---|---|
| 适用用户 | 所有用户（不限是否已预约） | 已完成预约 |
| 触发时机 | 活动开启时，每位用户仅显示一次。判断依据为**会员账号**，非装置；换装置或多装置登入，皆视为已读、不重复显示。 | 已达成领奖条件，且奖励尚未领取 |
| 红点消失 | 进入活动页后消失，此后不再重复 | 领取奖励后立即消失 |
| 开关关闭时 | 无论用户状态，全部隐藏 | 无论用户状态，全部隐藏 |

#### 判断逻辑表：两情境组合下的呈现结果

> 数字角标固定规则：**数字＝可领取奖励数量；数量为 0 时（代表只有开启提醒、尚无奖励可领），改以「1」表示**。

| 情境一：活动开启（未读） | 情境二：奖励可领（未领） | 首页浮窗／卡片红点 | 底部导览／Banner／Expand 数字角标 |
|:---:|:---:|---|---|
| 是 | 是 | 显示 | 显示，数字＝可领取奖励数量 |
| 是 | 否 | 显示 | 显示，数字＝**1**（无奖励可领，以 1 代表开启提醒） |
| 否 | 是 | 显示 | 显示，数字＝可领取奖励数量 |
| 否 | 否 | 不显示 | 不显示 |

#### 显示位置

| 位置 | 平台 | 说明 |
|---|---|---|
| 首页浮窗图标右上角（收起状态） | 全平台 | 红点 |
| 浮窗活动卡片右上角 | 全平台 | 红点 |
| 底部导航「奖励中心」图标 | 全平台 | 数字角标；情境一或情境二任一成立即显示，情境二成立时数字＝可领取奖励总数，仅情境一成立时数字为 1 |
| Promotion Banner 右上角 | 全平台 | 数字角标；规则同上，但以对应活动为单位计算 |
| 折叠状态 Expand 按钮 | H5 / App（PC 不显示） | 数字角标；数字＝未展开活动中情境一或情境二成立的提醒总数（情境二以可领奖励数量计入，仅情境一成立的活动各计 1）；展开后隐藏 |

### 3.2 预约成功弹窗

> 🆕 **8/25 新增**：预约操作成功时立即弹出，展示推荐游戏

「预约成功」弹窗为**既有样式**（标题／副标／CTA 按钮／右上角关闭「✕」均不异动），本次仅新增「为你推荐」游戏区块，以及 CTA 按钮点击后新增的跳转逻辑。

#### 触发规则

- 触发时机：玩家完成预约操作、系统判定**预约成功**的瞬间立即弹出
- 推荐游戏取值来自后台步骤 4「推荐游戏」设置，**最多 4 款**；显示顺序依选择弹窗中的固定列表顺序（同「适用游戏范围」的类别／游戏排列方式），**非**依后台点选的先后顺序
- 后台「推荐游戏」**未选择任何游戏**时，弹窗呈现**既有弹窗样式**（不含「为你推荐」区块，与本次新增前完全一致）
- 每次预约成功皆弹出，不因玩家先前已关闭过而抑制

#### 排版规则：推荐游戏数量与呈现方式

> 卡片仅显示**游戏缩略图**，不附加游戏名称文字；固定采 **2 栏**排列，依实际数量决定行数与对齐方式。

| 推荐游戏数量 | 排版方式 | 说明 |
|:---:|:---:|---|
| 0 款 | 既有弹窗样式 | 不显示「为你推荐」标题与游戏卡片，呈现方式与本次新增前完全一致 |
| 1 款 | 单张居中 | 仅 1 张卡片，置于弹窗正中间 |
| 2 款 | 左右一排 | 2 张卡片同排左右并列 |
| 3 款 | 2＋1 三角形 | 第一排 2 张左右并列，第二排 1 张水平居中 |
| 4 款（上限） | 2×2 两排 | 每排 2 张，共两排，无居中特例 |

#### 点击行为（依后台是否配置推荐游戏，穷举全部情境）

| 情境 | 操作 | 跳转结果 |
|---|---|---|
| 情境一：后台**未配置**推荐游戏（0 款） | 点击 CTA 按钮（既有按钮，本次不改文案） | 跳转至**首页**（既有行为，不异动） |
| 情境二：后台**已配置**推荐游戏（1～4 款） | 点击任一推荐游戏卡片 | 关闭弹窗，跳转至**该卡片对应的游戏** |
| 情境二：后台**已配置**推荐游戏（1～4 款） | 点击 CTA 按钮 | 关闭弹窗，**随机**跳转至已配置的推荐游戏中的其中一款 |
| 不限情境 | 点击右上角关闭「✕」 | 关闭弹窗，停留在原页面（既有行为，不异动） |

## 4. 后台规格

### 4.1 步骤 2 — 活动图片

新增「活动列表设置」区块。设置首页浮窗图片、活动列表图片及活动备注。活动列表图片用于前台 Rewards → Promotion 分类显示（Event time／标题依步骤 1 配置，排序依下方「排序」数值，取代旧版依角标排序的规则）。

#### 新增字段说明

| 字段 | 必填 | 说明 |
|---|:---:|---|
| **列表开关** | 必填 | 控制本活动是否出现在前台 Rewards → Promotion 列表。预设开启。与首页浮窗开关互不影响、各自独立设置。 |
| **列表图片** | — | PC / H5 各一张，用于前台 Promotion 列表展示；两端各自独立，PC 有上传则 PC 显示入口，H5／App 有上传则该端显示入口，互不影响。格式：png、bmp、jpg、gif、webp；5MB 以内。 |
| **排序** | 必填 | 预设 0（最优先）；不可负数，上限 9999；与其他活动在 Promotion 列表共用同一排序池，独立于首页浮窗排序。 |

#### 注意事项

- 「活动列表设置」区块紧接「首页浮窗设置」下方，两者各自独立
- 关闭列表开关后，该活动不出现于前台 Promotion 列表，但首页浮窗不受影响
- 列表开关开启时，PC 与 H5／App 两端**各自独立判断**：该端已上传列表图片才出现该活动的入口，未上传则该端不显示此活动，不影响另一端的显示

#### 提示文案（操作失败／成功）

| 情境 | 提示文案 |
|---|---|
| 上传格式不符 | 图片格式不符，请上传 png、bmp、jpg、gif、webp 格式的文件 |
| 上传超过 5MB | 图片大小超过 5MB，请重新上传 |
| 排序数值超出范围 | 排序数值需介于 0～9999 之间，请重新输入 |
| 保存成功 | 设置已保存 |

### 4.2 步骤 4 — 活动条件

预约达成条件、参与门槛、奖项配置等设定与第一版一致，未变更。

#### 通用设置（v2 新增，参考周卡活动既有开关样式）

| 字段 | 说明 |
|---|---|
| 活动开启提醒 | 开启后，对所有用户显示**一次**红点，进入活动页即消失 |
| 已预约用户奖励领取提醒 | 开启后，**可领取奖励时**前台显示红点 |

> 两者**各自独立、预设皆为开启**，触发条件互不影响、可能同时成立（同时成立时首页浮窗／卡片仍只显示单一红点，不会重叠）。开关只影响「红点是否显示」，站内信维持**系统默认行为**，不提供活动层级开关。

##### 注意事项

- 两颗开关的触发逻辑详见前台规格「红点提醒」，两者判断条件互相独立、可能同时成立，呈现方式见判断逻辑表
- 活动开启提醒需记录各用户的已读状态，确保每人每活动仅显示一次
- 两颗开关统一在步骤 4 配置，活动列表页不另设重复控制入口

#### 通用设置（既有部分，节录）

| 字段 | 说明 |
|---|---|
| 适用游戏范围 | 既有栏位，本次不异动 |
| 推荐游戏 🆕8/25新增 | 紧接在「适用游戏范围」栏位下方，置于步骤 4 页面最下方 |

#### 新增字段说明（推荐游戏）🆕 8/25 新增

| 字段 | 必填 | 说明 |
|---|:---:|---|
| **推荐游戏** | 否 | **位置**：置于步骤 4「活动条件」页最下方，紧接在既有「适用游戏范围」栏位下方（「适用游戏范围」本身不异动，两者一并置底）<br>**选择方式**：与「适用游戏范围」使用同一个游戏选择弹窗，但仅能逐一勾选**个别游戏**；弹窗内**不含「体育」类别**（体育为投注类型而非单一游戏，无法产生对应游戏卡片，故排除），且**不提供「全选」及各厂商／类别层级的整批勾选**（勾选厂商／类别＝该厂商／类别下全部游戏，一次可能远超 4 款上限，故此二层级的勾选框皆不可勾选）<br>**数量上限**：最多 4 款；达上限后其余游戏灰显不可选，须先取消勾选才能再选其他游戏<br>**用途**：玩家预约成功时，于前台「预约成功」弹窗推荐显示<br>**未选择时**：弹窗不显示推荐游戏区块 |

##### 注意事项（推荐游戏）🆕 8/25 新增

- 「推荐游戏」为独立选择项，与「适用游戏范围」互不影响，可分别勾选不同游戏，彼此无从属关系
- 「推荐游戏」选择弹窗**不含「体育」类别**，此点与「适用游戏范围」选择弹窗（含体育）不同
- 「推荐游戏」选择弹窗中，「全选」勾选框及各**厂商／类别层级**的勾选框皆**不可勾选**（灰显不可选），仅能逐一勾选**个别游戏**；原因：厂商／类别层级勾选＝该厂商／类别下全部游戏，一次可能远超「最多 4 款」的上限

#### 提示文案（操作失败／成功）

| 情境 | 提示文案 |
|---|---|
| 切换任一开关 | 即时生效，无需另外保存；切换后顶部提示「设置已更新」 |
| 推荐游戏已选满 4 款时 🆕8/25 | 其余游戏选项呈灰显 disabled 状态（无法点击勾选）；鼠标悬停（hover）该灰显选项时显示提示「已达上限，请先取消勾选其他游戏」，须先取消勾选才能替换 |
