充值页 · 优惠券未达最低充值提醒 · v1

范围：前台充值页（H5）　｜　后台：不涉及

本次摘要： 修改 勾券但金额未达最低充值时，Submit 不再锁定； 新增 点 Submit 弹出底部提醒，让会员选择补足金额或放弃优惠继续充值。

1. 需求目的

现况：会员勾了充值优惠券，但输入的金额低于券的最低充值金额时，Submit 按钮会被锁住，会员只能自己回头改金额或取消勾选，流程卡住、也不知道差多少。

本次改成不锁按钮，改用底部弹窗告诉会员「还差多少、补足能多拿多少」，让会员自己决定补足金额或放弃优惠直接充值，减少流失。

2. 前台 · 充值页

对应左侧原型。本页只有 Promotions 区的优惠券与 Payment Amount 区的 Submit 按钮有关联，其他区块不动。

2.1 Submit 按钮的锁定判断 修改

  1. 勾选优惠券、且输入金额低于券的「Min Deposit」时，Submit 不再变灰锁定，维持可点击。
  2. 金额输入框下方的红字 Deposit amount less than min limit. 与输入框红框照既有显示，不异动。
  3. 金额为 0 或空白时，Submit 照既有维持锁定，不异动。
  4. 未勾选优惠券时，Submit 照既有规则，不异动。

2.2 底部提醒弹窗 新增

触发条件：勾选优惠券、输入金额大于 0 且低于券的 Min Deposit，会员点击 Submit。此时不送出充值，先从页面底部弹出提醒。

2.2.1 文案（英文由运营提供，照抄）

标题：Unlock Your Bonus!

第一行：Minimum deposit: ₱{Min Deposit}

第二行：Deposit ₱{X} more to get ₱{Bonus} extra!

按钮 1：Deposit more

按钮 2：Skip Bonus

变量取值格式例（5% 券、上限 ₱5、Min 100、输入 20）
{Min Deposit}该券的最低充值金额与券面「Min Deposit」相同，保留两位小数、千分位100.00
{X}Min Deposit − 目前输入金额同上80.00
{Bonus}以 Min Deposit 充值可拿到的奖励＝Min Deposit × 券的百分比，超过上限取上限与券面「Capped At」及既有试算条相同格式5

文案长度：英文固定、数字会变，内容依弹窗宽度自然换行，不截断、不加省略号。字级不小于 12px。

2.2.2 样式

  1. 由页面底部向上弹出，白底、上方圆角，背景压半透明黑色遮罩，弹窗出现时页面其他区域不可操作。
  2. 内容由上到下：标题、两行说明、两颗并排等宽按钮。
  3. 「Deposit more」为主要按钮（蓝底白字，右侧）；「Skip Bonus」为次要按钮（白底灰框，左侧）。

2.2.3 交互

会员操作结果
点「Deposit more」 关闭弹窗，回到充值页，优惠券维持勾选，金额维持原输入，游标停在金额输入框让会员补足。不送出充值。
点「Skip Bonus」 关闭弹窗，自动取消勾选该优惠券，并以目前输入金额直接送出充值（后续走既有送出流程）。本笔不套用优惠。
点遮罩（弹窗以外区域） 同「Deposit more」：关闭弹窗、什么都不改、不送出。
  1. 弹窗关闭后不记忆：会员再次以同样条件点 Submit，仍会再弹一次。
  2. 弹窗显示期间会员若改了金额（例如用实体返回键关闭），以关闭当下的输入金额重新判断，不用弹窗上的旧数字。

2.3 情境穷举 含不异动项

#优惠券输入金额Submit 状态点 Submit 后异动
1未勾选0 / 空白锁定—不异动
2未勾选> 0可点直接送出（走既有流程）不异动
3勾选0 / 空白锁定—不异动
4勾选> 0 且 < Min Deposit可点（原本锁定）弹出 2.2 底部提醒，不送出修改＋新增
5勾选≥ Min Deposit可点直接送出，套用优惠（走既有流程）不异动

2.4 判断流程（点 Submit 时）

  1. 1有勾选优惠券吗？没有 → 直接送出（既有）。
  2. 2输入金额 ≥ 该券 Min Deposit 吗？是 → 直接送出，套用优惠（既有）。
  3. 3否 → 弹出底部提醒，等会员选择。
  4. 4选 Deposit more → 关弹窗、回页面补金额；选 Skip Bonus → 取消勾选券、直接送出。

3. 本次未涉及之既有规则

  1. 优惠券的显示条件、券面内容（百分比、Capped At、Turnover、Min Deposit）与勾选方式。
  2. 支付方式本身的最低／最高充值限制及其提示文案。
  3. 金额为 0 或空白时的锁定、红字提示。
  4. Submit 送出后的既有流程（跳转支付、成功／失败提示）。
  5. 后台所有设定。
